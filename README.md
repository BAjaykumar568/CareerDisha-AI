# CareerDisha AI 🎓

**From Confusion to Career Clarity**

A responsive career-guidance web application prototype for Indian fresh graduates. The project combines skill self-assessment, goal-based learning plans, learning-resource discovery, and job-description skill comparisons in one interface.

> **Project status:** Functional educational prototype built as an extension of a Jio AI Foundations App Architect capstone blueprint. The offline application uses rule-based guidance. A *separate, optional* Node.js endpoint can call Gemini for Disha Coach responses. This is **not** a deployed AI recommendation model, live job platform, or placement service.

## Features

| Feature | What it does | Implementation |
| --- | --- | --- |
| Skill profile | Edit existing skills and career objective | Browser form + local state |
| Career roadmaps | Roadmap templates for five technology roles with milestones and suggested projects | Predefined data + progression rules |
| Job readiness | Extracts known skills from pasted job descriptions and compares them with self-reported skills | JavaScript keyword/alias matching; **not** a trained ML model |
| Learning resources | Offers role-relevant documentation and learning links | Curated data and rule-based ranking |
| Progress tracker | Marks milestones complete and updates dashboard | Browser `localStorage` |
| Disha Coach | Answers common preparation questions | Offline scripted guidance; optional **Gemini API** when server configured |
| Responsive design | Desktop sidebar and mobile navigation | HTML/CSS/JavaScript |

## Interface preview

The working app is contained in [`index.html`](index.html). Open it locally to explore the dashboard, learning roadmap, job-readiness analyzer and responsive layouts. Screenshot assets are available in the separately prepared full project package and can be added to this repository later.

## Run locally (no dependencies)

1. Download this repository as a ZIP, then extract it.
2. Open **`index.html`** in Chrome, Edge, Firefox, or Safari.
3. Go to **My Roadmap** to generate a role-based plan; open **Job Analyzer** to compare a sample job description.

No sign-in or API key is required for offline features. The first visit loads a **fictional example learner**; replace it in **My Profile**.

### Optional Gemini-backed Disha Coach

A minimal Node.js HTTP server is included. It requires **Node.js 18+** and a Gemini API key supplied as a server environment variable.

Windows PowerShell:

```powershell
$env:GEMINI_API_KEY="YOUR_KEY_HERE"
node server.js
```

macOS / Linux:

```bash
GEMINI_API_KEY="YOUR_KEY_HERE" node server.js
```

Then open <http://127.0.0.1:3000>. Only Disha Coach calls the API. The roadmap generator and skill analyzer continue to run locally as rule-based functions. Never commit API keys or place them in frontend code. API access may require appropriate account permissions, pricing, and supported model availability.

## GitHub Pages deployment (static demo)

The offline prototype can be hosted with **GitHub Pages** because `index.html` is self-contained.

1. Create a public GitHub repository (suggested name: `CareerDisha-AI`).
2. Upload the **contents of this folder**, including `index.html`, to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch** and choose **`main`** with **`/(root)`**, then save.
5. After deployment, GitHub will display the live Pages URL. Use the URL GitHub actually provides; it is not generated by this repository.

**GitHub Pages limitation:** It hosts the static offline demo only. `server.js` and the live Gemini API endpoint do **not** run on GitHub Pages. Never add a Gemini API key directly into the frontend to bypass this limitation.

For the newest GitHub Pages setup steps, consult [GitHub Docs](https://docs.github.com/en/pages/quickstart).

## Validation

Browser-based smoke tests cover roadmap generation, milestone completion, job-skill comparison, adding gaps to the roadmap, resources, coach fallback, profile persistence and mobile navigation. To run the test script locally, install Python Playwright and a compatible Chromium browser first, then run `python test_app.py`. The tests have been run in a controlled local test environment; public deployment has **not** been performed here.

## Privacy and limitations

- Local demo saves data in the **current browser** only. It is not an online account or backed-up database.
- Self-reported skills and completion checkmarks are **not** independently verified proficiency.
- The analyzer recognizes a limited built-in skill vocabulary and can miss requirements or interpret a term incorrectly.
- The demo does **not** include live job listings, employer partnerships, auto-apply, model training, or employment guarantees.
- If Gemini is enabled, content of Disha Coach questions and limited career context are forwarded to the external Gemini service. Review provider terms and avoid sharing confidential information.
- Clear locally saved data via **My Profile → Delete local data**; browser settings may also remove it.
